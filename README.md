# Astrea — plugins pour Wazo

Outils d'administration pour les plateformes Wazo Entreprise, publiés par
Astrea. Ce dépôt est servi par GitHub Pages : il ne contient que les fichiers
installables, sans identifiant ni token.

| Dossier | Contenu | Où ça s'installe |
|---|---|---|
| [admin-tools/](admin-tools/README.md) | Plugin Portal **Astrea Admin Tools** (menu du même nom dans le portail ; module BLF Manager) | Portail Wazo : `https://briceaesir.github.io/astrea-wazo-plugins/admin-tools/manifest.json` |
| [provd/](provd/README.md) | Scripts serveur : blocs Astrea du `base.tpl` personnalisé des plugins provd (touches ligne Yealink) | Stack Wazo, en root |

Tutoriel d'installation : [admin-tools/INSTALLATION.md](admin-tools/INSTALLATION.md).
