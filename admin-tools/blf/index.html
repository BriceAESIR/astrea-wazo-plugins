    L'étiquette d'un utilisateur, c'est le texte affiché sur les touches qui le supervisent chez ses collègues. Vide = son nom complet.

    Rien n'est enregistré en dehors des touches : l'outil lit les touches de tous les postes et retient le libellé le plus utilisé pour chaque personne. Il est repris pour les nouvelles touches, dans l'éditeur et le déploiement en masse.

    Créez ou modifiez un modèle (touches ligne comprises), puis appliquez-le à plusieurs utilisateurs en une fois. Les modèles sont enregistrés dans les « Modèles de touches » de Wazo ; le nombre de touches ligne est noté dans le nom (blf-linekeys=N).

    Applique un même jeu de touches à plusieurs utilisateurs en une fois. Sur chaque poste, la touche qui vise son propriétaire est retirée et les suivantes remontent. En mode « Remplacer », le nombre de touches ligne du modèle est appliqué (postes Yealink) ; en mode « Ajouter », celui de chacun est conservé.

    Les touches sont écrites dans les touches propres à chaque utilisateur : le modèle Wazo n'est pas rattaché, sinon chacun aurait sa propre touche.

    À utiliser à la place des « Modèles de touches » et des touches de la fiche utilisateur de Wazo.

    Gérez les touches des postes ici plutôt qu'avec les outils de base de Wazo (« Modèles de touches », touches de la fiche utilisateur). Cet outil respecte la disposition réelle des postes (pages, modules, touches ligne), ne fait jamais superviser un utilisateur par lui-même et garde les libellés à jour. Une modification faite ailleurs peut être écrasée ou décaler les touches. Ne modifiez jamais une touche directement sur le téléphone : elle ne pourrait plus être gérée depuis Wazo.
